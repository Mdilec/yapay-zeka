# Yıldız Tozu Imparatorluğu+

Idle/clicker game inspired by the MIT-licensed [Stardust Tycoon](https://github.com/Noah-Simons/Stardust-Tycoon) (Noah Simons, 2026). Mechanics were studied and the game was rewritten from scratch with a testable engine.

Improvements: pure engine + tests, closed-form buy-max, one-time upgrades, crit clicks, golden stars, achievements (+2% each), prestige with Cosmic Essence shop, offline progress (8h cap), save import/export and validation.

Run: open `index.html` in a browser. Tests: `npm test`.
